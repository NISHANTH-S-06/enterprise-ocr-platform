# Task 8 Rollback Plan

Task 8 changes are limited to backup archival, cache deletion, and release documentation/scripts.

## Backup Restoration

Backend backups preserve their original path beneath `backups/backend/`. Restore one file with:

```powershell
Move-Item -LiteralPath "backups/backend/app/<relative-path>" -Destination "app/<relative-path>"
```

Frontend backups are stored in `backups/frontend/`. Restore one file with:

```powershell
Move-Item -LiteralPath "backups/frontend/<filename>" -Destination "frontend/<filename>"
```

Alembic backups are stored in `backups/alembic/`. Restore with:

```powershell
Move-Item -LiteralPath "backups/alembic/<filename>" -Destination "alembic/<original-relative-path>"
```

The exact original and archive paths are recorded in `docs/CLEANUP_LOG.md`.

## Cache Restoration

Deleted Python and pytest caches do not require restoration. They are regenerated by compile and test commands.
